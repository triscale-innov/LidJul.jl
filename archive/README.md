# Historical experiments

These sources preserve the pre-refactoring implementation for research provenance.
They are not part of the supported API or the test suite, and are not expected
to run with the current solver contract. Use the maintained scripts in `examples/`
and `benchmark/`, documented by the Documenter site, for new experiments.

The cavity implementation descends from Benjamin Seibold's MIT18086 Navier--Stokes
example. The multigrid implementation descends from Harald Köstler's Multigrid HowTo.
Their original attribution comments are preserved.
